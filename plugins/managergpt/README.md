# ManagerGPT

A personalized AI **Operating System** for leaders and managers — built around the ManagerGPT framework of shifting from **Re-Actor to Author**, across the **Outer Game** (managing work, time, and others) and the **Inner Game** (managing yourself).

Start with `/managergpt:onboarding` to set up your workspace, connect your tools, map your task system, and generate your context files and standing instructions. Then use the skills below day to day.

## Skills

| Command | What it does |
|---|---|
| `/managergpt:onboarding` | Set up your Operating System (Hire → Onboard → Intake → Gossip → Test Drive → automations). |
| `/managergpt:weekly-preview` | Close out the week and author the next one — defined outcomes, delegation, then Deep Work. |
| `/managergpt:plan-my-day` | Daily Defining — what today is for, after your buffer. |
| `/managergpt:delegate-with-clean-handoffs` | Delegate with the 5 W's (Who / What / By When / Where / Why). |
| `/managergpt:decline` | Draft a meeting decline in your voice — protect Deep Work without burning the relationship. |
| `/managergpt:leverage-quadrant` | Your Genius work vs. what to delegate (Impact × ability of others). |
| `/managergpt:inner-dialogue` | Relate to a difficult emotion from Self and uncover what it's protecting (IFS-inspired). |
| `/managergpt:catching` | Rehearse, prep, and debrief empathic listening (Catching) — feelings + the cares at the core. |
| `/managergpt:feedback-gain` | Prepare, refine, or practice feedback with GAIN. |
| `/managergpt:coaching-grow` | Rehearse, prep, and debrief coaching — empowering questions + GROW. |
| `/managergpt:meta-prompt` | Create and improve prompts. |
| `/managergpt:tiny-habit` | Make a new behavior stick (BJ Fogg). |
| `/managergpt:retrospective` | Tune your OS — review your history, spot patterns, update working-style.md. Runs monthly. |
| `/managergpt:protect` | Optional security review of your setup. |

## How it fits together

`onboarding` writes your context files — `about-me.md`, `working-style.md` (Outer Game / Inner Game / Both), `org-and-team-context.md`, and (for external-facing roles) `brand-voice.md` — plus your Global Instructions. The planning skills read `working-style.md` to find where your tasks live and how much buffer to leave; the interpersonal skills draw on your Inner Game and (if installed) Familiar. `retrospective` closes the loop — it reads what the planning skills recorded over time and proposes updates back to `working-style.md`, so the OS tunes itself to you. Everything runs in **Claude Cowork** and **Codex**.
