# ManagerGPT

A personalized AI **Operating System** for leaders and managers — built around the ManagerGPT framework of shifting from **Re-Actor to Author**, across the **Outer Game** (managing work, time, and others) and the **Inner Game** (managing yourself).

Start with `/managergpt:onboarding` to set up your workspace, connect your tools, map your task system, and generate your context files and standing instructions. Then use the skills below day to day.

## Skills

| Command | What it does |
|---|---|
| `/managergpt:onboarding` | Set up your Operating System (Hire → Onboard → Intake → Gossip → Test Drive → automations). |
| `/managergpt:weekly-preview` | Close out the week and author the next one — defined outcomes, Deep Work, delegation. |
| `/managergpt:plan-my-day` | Daily Defining — what today is for, after your buffer. |
| `/managergpt:clean-handoffs` | Delegate with the 5 W's (Who / What / By When / Where / Why). |
| `/managergpt:leverage-quadrant` | Your Genius work vs. what to delegate (Impact × ability of others). |
| `/managergpt:inner-dialogue` | Move through a difficult emotion to the yearning underneath. |
| `/managergpt:catching` | Reflect feelings and the cares at the core. |
| `/managergpt:feedback-gain` | Prepare, refine, or practice feedback with GAIN. |
| `/managergpt:coaching-grow` | Coach with empowering questions and the GROW model. |
| `/managergpt:meta-prompt` | Create and improve prompts. |
| `/managergpt:tiny-habit` | Make a new behavior stick (BJ Fogg). |
| `/managergpt:protect` | Optional security review of your setup. |

## How it fits together

`onboarding` writes your context files — `about-me.md`, `working-style.md` (Outer Game / Inner Game / Both), `org-and-team-context.md`, and (for external-facing roles) `brand-voice.md` — plus your Global Instructions. The planning skills read `working-style.md` to find where your tasks live and how much buffer to leave; the interpersonal skills draw on your Inner Game and (if installed) Familiar. Everything runs in **Claude Cowork** and **Codex**.
